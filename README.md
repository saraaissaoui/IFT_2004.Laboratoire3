## Fichier .gitignore

Le fichier .gitignore contient les motifs suivants :

- validate* : ignore les fichiers dont le nom commence par « validate ».
- *.csv : ignore tous les fichiers ayant l’extension .csv.
- data/ : ignore le répertoire data et son contenu

## Organisation du dépôt

C'est la branche master qui contient les fichiers principaux du laboratoire.
